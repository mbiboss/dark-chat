# DARK CHAT 🖥️

একটি হ্যাকার/টার্মিনাল থিমযুক্ত রিয়েল-টাইম চ্যাট অ্যাপ্লিকেশন যা GitHub Pages এ চলে।

## বৈশিষ্ট্য ✨

- 🖤 **Hacker Terminal Theme** - ডার্ক মোড, সবুজ টেক্সট, কমান্ড টার্মিনাল স্টাইল
- 🔐 **Encrypted Messaging** - এন্ড-টু-এন্ড এনক্রিপশন সাপোর্ট
- 📱 **Progressive Web App** - অফলাইনে কাজ করে, ইনস্টল করা যায়
- 🌐 **Firebase Real-time Database** - তাৎক্ষণিক মেসেজ সিঙ্ক
- 👥 **Admin Panel** - অ্যাডমিন কন্ট্রোল পেনেল
- 📢 **Push Notifications** - ব্রাউজার নোটিফিকেশন
- 💻 **WebRTC Support** - পিয়ার-টু-পিয়ার কানেকশন

## ডিপ্লয়মেন্ট 🚀

এই প্রজেক্ট GitHub Pages এ স্বয়ংক্রিয়ভাবে ডিপ্লয় হয়:

1. GitHub এ রিপোজিটরি সেটিংস খুলুন
2. **Pages** সেকশনে যান
3. **Deploy from a branch** সিলেক্ট করুন
4. ব্রাঞ্চ: `main` এবং folder: `/ (root)` সিলেক্ট করুন
5. `Save` করুন

GitHub Actions স্বয়ংক্রিয়ভাবে প্রতিটি পুশের সাথে ডিপ্লয় করবে।
